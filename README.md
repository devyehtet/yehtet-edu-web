# Ye Htet - Digital Edu LMS

A local React + Vite + Tailwind prototype for a Digital Marketing LMS website.

## Run locally in VS Code

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal, usually:

```bash
http://localhost:5173
```
